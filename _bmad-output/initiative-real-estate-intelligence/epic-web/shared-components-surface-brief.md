# Shared Placa components

Mode: Operate. Scope: reusable property row, figure/provenance, their real median consumer and
accessibility evidence. This extends the established world rather than designing a new page. Search
remains its honest incremental entry screen; the component gallery exists only in test fixtures.

## Direction contract

THESIS: Make each backend number accountable and each property recognizable; reject anonymous cards,
thumbnail-led rows and unsupported statistics.

OWN-WORLD: Inherit enamel blue, porcelain, five zone colors and wayfinding yellow. Use existing
Barlow/Barlow Condensed, flat ruled rows, outlined Asking tags and compact evidence. D-055 darkens
only the essential control-border token.

STORY: The visitor reads a price, verifies its source and computation, and follows one property
link. Missing values remain missing; returned-to-market and above/below comparisons use words, not
color alone.

FIRST VIEWPORT: Preserve the actual place shell and plate above its 48px median and 12px evidence.
Shared row has type/size and block left, asking price/per-m² right, listing/time metadata below; no
photos. At 390px long content wraps without shrinking typography.

FORM: Established Placa component composition, inherited rather than ranked; seed key:
inherited-placa-components (no new roll). The signature interaction is native keyboard activation of
a single property row with visible enamel focus.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the
verdict, DESIGN.md, and every shipping raster carrying its provenance

## Proof and limits

Both locales, 390/960/1440px, real owned Compose median and parsed synthetic property responses;
explicit labelled component edge fixtures. Full-page axe plus semantic token contrast, keyboard,
geometry, font and screenshot checks. No public component fixture, new business computation, dead
method route, V2 navigation or certification of complete WCAG before story 6.12.
